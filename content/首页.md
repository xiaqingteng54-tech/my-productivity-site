# 🏠 首页

> [!tip] 使用说明
> 每次打开 Vault 先看这里：**今天要干什么**（今日待办）+ **正在推进什么**（活跃项目）。

---

## ✅ 今日待办

### 一、今天到期与已逾期

```dataview
TASK
FROM "0-Inbox" OR "1-Projects" OR "2-Areas" OR "3-Resources"
WHERE !completed AND due AND due <= date(today)
SORT due ASC
```

### 二、全部未完成任务（按来源文件分组）

```dataview
TASK
FROM "0-Inbox" OR "1-Projects" OR "2-Areas" OR "3-Resources"
WHERE !completed
GROUP BY file.link
```

## 🚀 活跃项目（近 3 天有改动）

```dataview
TABLE WITHOUT ID
  file.link AS "项目",
  status AS "状态",
  file.mtime AS "最后修改"
FROM "1-Projects"
WHERE file.mtime >= date(today) - dur(3 days)
SORT file.mtime DESC
```

---

## 📥 收件箱速览

```dataview
LIST
FROM "0-Inbox"
WHERE file.name != this.file.name
SORT file.ctime DESC
LIMIT 10
```

## 📊 系统状态

```dataviewjs
const inbox = dv.pages('"0-Inbox"').length;
const proj  = dv.pages('"1-Projects"').length;
const areas = dv.pages('"2-Areas"').length;
const res   = dv.pages('"3-Resources"').length;

const tasks = dv.pages('"0-Inbox" OR "1-Projects" OR "2-Areas" OR "3-Resources"')
  .file.tasks.where(t => !t.completed).length;

dv.table(
  ["指标", "数值"],
  [
    ["未完成任务总数", tasks],
    ["收件箱条目", inbox],
    ["进行中项目", proj],
    ["领域（Areas）", areas],
    ["资源笔记", res],
  ]
);
```
