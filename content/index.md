# 👋 欢迎来到我的知识库

这里用 **Obsidian + PARA + GTD** 日常维护，通过 **Quartz** 发布成静态站点。

> 这个页面是给外部访问者看的「门面」；日常使用的仪表盘在 [[首页]]。

## 内容分区

| 分区 | 用途 |
| --- | --- |
| 0-Inbox | 随手记、待整理的念头与临时材料 |
| 1-Projects | 有明确目标和截止时间的项目 |
| 2-Areas | 需要长期维护、没有终点的领域 |
| 3-Resources | 参考资料、主题笔记与素材库 |
| 4-Archives | 已完成或不再活跃的内容 |
| 5-System | 模板、复盘与系统配置 |

## 快速入口

- [[首页]] — 仪表盘：今日待办与活跃项目
- [[每周复盘模板]] — 每周复盘的固定格式

## 说明

- 笔记均为本地 Markdown 文件，随时可迁移、可版本管理
- 站点由 Quartz 从 Markdown 自动构建，改完笔记执行一次同步即可更新
